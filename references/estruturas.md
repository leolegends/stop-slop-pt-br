# Estruturas para evitar

## Contraste binário

Cria drama falso. Diga o ponto direto.

| Padrão | Problema |
| ------ | -------- |
| "Não é X. É Y." / "Não é sobre X, é sobre Y." | Virada telegrafada |
| "Mais do que X, é Y." | Mesmo truque com outra roupa |
| "Não se trata de X, mas de Y." | Negação antes da afirmação |
| "O problema não é X. O problema é Y." | Reenquadramento de fórmula |
| "Parece X, mas na verdade é Y." | Armação e revelação |
| "Não apenas X, mas também Y." | Soma disfarçada de profundidade |
| "Deixa de ser X e passa a ser Y." | Arco de transformação falso |

**Em vez disso:** "O problema é Y." Corte a negação.

## Lista pela negação

Dizer o que a coisa não é antes de dizer o que é.

| Padrão | Problema |
| ------ | -------- |
| "Não é um X. Não é um Y. É um Z." | Suspense fabricado |
| "Não foi X. Não foi Y. Foi Z." | O mesmo, no passado |

**Em vez disso:** diga Z.

## Fragmentação dramática

Frase picada para dar ênfase soa como profundidade fabricada.

| Padrão | Problema |
| ------ | -------- |
| "[Substantivo]. Só isso. Esse é o segredo." | Simplicidade encenada |
| "Rápido. Seguro. Simples." | Staccato publicitário |
| "Isso destrava algo. Liberdade." | Revelação artificial |
| "O resultado? Incrível." | Pergunta e resposta de vitrine |

**Em vez disso:** frase completa. Deixe o conteúdo trabalhar.

## Armações retóricas

Anunciam a ideia em vez de entregar.

| Padrão | Problema |
| ------ | -------- |
| "E se eu te dissesse que...?" | Pose socrática |
| "Já parou para pensar...?" | Pergunta de palestra motivacional |
| "Sabe o que isso significa?" | Pergunta respondida na linha seguinte |
| "Pense comigo:" | Condescendente |
| "E tudo bem." | Permissão que ninguém pediu |
| "Seja X, seja Y, ..." | Abertura de comercial |

**Em vez disso:** faça a afirmação.

## Agência falsa

Coisas fazendo ação de gente. A IA usa isso para não nomear quem age.

| Padrão | Problema |
| ------ | -------- |
| "Os dados mostram" | Dado não mostra; alguém leu e concluiu |
| "O mercado exige" | Mercado não exige; cliente compra ou não |
| "A decisão surgiu" | Alguém decidiu |
| "A cultura mudou" | As pessoas mudaram o comportamento |
| "A reclamação virou correção" | Alguém corrigiu |
| "O projeto ganhou vida" | O time entregou |
| "A conversa caminhou para" | Alguém conduziu |

**Em vez disso:** nomeie a pessoa ou o time. Se não houver um, use "você".

## Narrador de longe

Flutuar acima da cena em vez de pôr o leitor nela.

| Padrão | Problema |
| ------ | -------- |
| "Ninguém planejou isso." | Observação sem corpo |
| "Isso acontece porque..." | Voz de professor |
| "As pessoas tendem a..." | Sociologia de sofá |
| "Muitas empresas enfrentam..." | Generalização sem fonte |

**Em vez disso:** "Você não acorda um dia e decide..." Ponha o leitor na situação.

## Voz passiva e "se" impessoal

Esconde quem age e tira a energia da frase.

| Padrão | Correção |
| ------ | -------- |
| "Foi realizado um levantamento" | "O time levantou" |
| "É recomendado que" | "Recomendo que" / "O jurídico recomenda que" |
| "Se faz necessário" | "Você precisa" / "O time precisa" |
| "Foram cometidos erros" | Diga quem errou |
| "Realiza-se a análise" | "Analisamos" |

Exceção: texto técnico em que o agente é irrelevante ("o endpoint foi descontinuado na v3").

## Começos de frase para evitar

| Padrão | Correção |
| ------ | -------- |
| "O que torna isso difícil é..." | "A restrição é..." e nomeie a restrição |
| "É aqui que entra..." | Diga o que entra |
| "Foi assim que..." | Conte o fato |
| Parágrafo começando com "Então," ou "Bom," | Comece pelo conteúdo |
| "Olha," / "Veja bem," | Corte |

## Ritmo

| Padrão | Correção |
| ------ | -------- |
| Lista de três ("rápido, seguro e eficiente") | Dois itens ou um |
| Pergunta respondida logo em seguida | Corte a pergunta |
| Todo parágrafo termina com frase de efeito | Varie o final |
| Travessão (—) no texto expositivo | Vírgula, ponto, dois-pontos ou parênteses |
| Várias frases curtas empilhadas | Junte algumas |
| "Nem sempre. Nem perfeitamente." | Ressalva disfarçada de consolo |
| Excesso de exclamação e emoji | Tire |

## Formatação

| Padrão | Correção |
| ------ | -------- |
| Título em Title Case ("Como Melhorar Seu Processo") | Só a primeira letra maiúscula ("Como melhorar seu processo") |
| Negrito em toda frase | Negrito só no que o leitor não pode perder |
| Bullet para tudo, inclusive raciocínio | Parágrafo quando a ideia é contínua |
| Emoji como marcador de lista | Marcador comum |

## Palavras absolutas

| Padrão | Problema |
| ------ | -------- |
| "sempre", "nunca", "todos", "ninguém", "qualquer um", "absolutamente" | Autoridade falsa. Use número ou caso concreto. |
