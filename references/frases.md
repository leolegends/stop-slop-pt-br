# Frases para cortar

## Aberturas que anunciam o assunto

Corte e comece pelo conteúdo.

- "Vale ressaltar que" / "Vale destacar que" / "Vale lembrar que"
- "É importante destacar" / "É importante mencionar" / "É importante notar"
- "Cabe mencionar" / "Cabe ressaltar"
- "Antes de mais nada" / "Primeiramente" / "Em primeiro lugar" (quando não há segundo lugar)
- "Sem mais delongas"
- "Vamos lá" / "Bora lá"
- "A verdade é que" / "O fato é que" / "A realidade é que"
- "Não é segredo que"
- "Deixa eu te contar" / "Preciso ser sincero"
- "O que eu acho interessante é"
- "Aqui está o ponto:" / "O ponto é:"
- "Dito isso," / "Posto isso," / "Isto posto,"
- "Nesse sentido," / "Nesse contexto," / "Diante disso," / "Sendo assim,"

## Bajulação e confirmação vazia

Corte. Responda direto.

- "Ótima pergunta!" / "Excelente pergunta!"
- "Você está certo" / "Você tem toda razão"
- "Faz total sentido"
- "Perfeito!" / "Com certeza!" / "Claro!" / "Certamente!"
- "Excelente ponto"
- "Entendo perfeitamente"

## Fechamentos de cortesia

Corte. O texto termina quando o conteúdo termina.

- "Espero ter ajudado"
- "Fico à disposição" / "Estou à disposição para dúvidas"
- "Qualquer dúvida, é só chamar"
- "Em suma," / "Em resumo," / "Em conclusão," / "Concluindo," / "Resumindo,"
- "Por fim, mas não menos importante"
- "E é isso!"

## Muletas de ênfase

Não acrescentam nada. Apague.

- "Ponto." / "Ponto final."
- "Pense nisso."
- "Leia de novo."
- "E isso muda tudo."
- "Isso importa porque"
- "Não se engane:"
- "Spoiler:" / "Alerta de spoiler:"
- "E o melhor:" / "E tem mais:"
- "Sim, você leu certo."

## Abertura de cenário genérica

- "No cenário atual"
- "Nos dias de hoje" / "Hoje em dia"
- "No mundo atual" / "Em um mundo cada vez mais conectado"
- "Na era digital"
- "Em tempos de"
- "No mundo corporativo"
- "No contexto atual"

## Jargão corporativo

Troque por palavra comum.

| Evite | Use |
| ----- | --- |
| Alavancar | Aumentar, usar |
| Potencializar | Aumentar, melhorar |
| Otimizar (genérico) | Diga o que melhora: tempo, custo, erro |
| Jornada (do cliente) | Caminho, etapas, uso |
| Ecossistema | Conjunto de produtos, sistemas |
| Sinergia | Trabalho conjunto |
| Robusto | Diga a propriedade: aguenta X req/s, tem retry |
| Agregar valor | Diga o valor |
| Fazer a diferença | Diga a diferença |
| Virada de chave | Mudança |
| Divisor de águas | Mudança grande (e diga qual) |
| Transformador / revolucionário | Diga o que muda |
| Mergulhar fundo / mergulho profundo | Analisar, estudar |
| Navegar pelos desafios | Lidar com |
| Desbravar | Explorar, começar |
| Pilar (fora de arquitetura) | Parte, base |
| Trazer à tona | Mostrar |
| Colocar na mesa | Propor |
| Alinhar expectativas | Combinar |

## Anglicismos de tradução

| Evite | Use |
| ----- | --- |
| Endereçar (um problema) | Resolver, tratar |
| No final do dia | No fim, no fundo (ou corte) |
| Performar | Ter desempenho, render |
| Aplicar para (vaga) | Candidatar-se |
| Fazer sentido (para tudo) | Ter lógica, servir (ou corte) |
| Mover o ponteiro | Mudar o resultado |
| Ter certeza que | Ter certeza de que |
| Suportar (no sentido de dar suporte) | Aceitar, ser compatível com |
| Deletar | Apagar, excluir |
| Reportar (no sentido de relatar) | Relatar, informar |

## Advérbios e locuções adverbiais

Corte advérbio de ênfase e de enrolação. Mantenha só os que dão informação (tempo, lugar, negação).

Ofensores comuns:

- "simplesmente", "basicamente", "literalmente", "realmente", "verdadeiramente"
- "extremamente", "totalmente", "completamente", "absolutamente"
- "significativamente", "efetivamente", "essencialmente", "fundamentalmente"
- "praticamente", "constantemente", "certamente", "definitivamente"
- "de fato", "sem dúvida", "com certeza", "de certa forma"
- "de forma eficiente", "de maneira significativa", "de modo geral"
- "inclusive" (como ênfase), "justamente", "exatamente"

## Adjetivos inflados

Sozinhos, não dizem nada. Troque por fato ou corte.

- "fundamental", "crucial", "essencial", "primordial", "imprescindível", "vital"
- "incrível", "poderoso", "inovador", "único", "excepcional"
- "um verdadeiro", "uma verdadeira"

## Burocratês

| Evite | Use |
| ----- | --- |
| Realizar a implementação | Implementar |
| Efetuar o pagamento | Pagar |
| Fazer uso de | Usar |
| Proceder com a análise | Analisar |
| Se faz necessário | É preciso (e diga quem precisa) |
| No que diz respeito a / No que tange a | Sobre |
| A nível de | Em, no |
| Através de (meio) | Por, com |
| Visando | Para |
| De forma a | Para |
| Com o objetivo de | Para |
| Tendo em vista que | Como, porque |
| Por meio deste | (corte) |

## Gerundismo

| Evite | Use |
| ----- | --- |
| Vou estar enviando | Vou enviar / Envio |
| Estaremos analisando | Vamos analisar / Analisamos |
| Vou estar verificando | Vou verificar |

## Metacomentário

O texto avança; não anuncia a própria estrutura.

- "Neste artigo, vamos ver..."
- "Ao longo deste texto..."
- "Como veremos a seguir..."
- "Deixa eu te explicar..."
- "Vou te mostrar passo a passo..."
- "Mas isso é assunto para outro post"
- "Isso não é um bug, é uma feature"

## Declarações vagas

Anunciam importância sem dizer qual. Corte ou troque pelo fato.

- "Os impactos são significativos"
- "As consequências são reais"
- "Isso é mais profundo do que parece"
- "Os motivos são estruturais"
- "O desafio é enorme"
- "Isso diz muito"
